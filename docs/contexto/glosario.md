# Glosario del Dominio - OficiosVecinos

Este documento define los términos de negocio y conceptos del dominio para mantener un lenguaje ubicuo claro y consistente.

---

## Términos Principales

- **Vecino**: Usuario registrado en la plataforma perteneciente a una zona o barrio específico.
- **Prestador / Oficio**: Vecino que ofrece un servicio técnico u oficio práctico (plomería, electricidad, carpintería, jardinería, etc.).
- **Publicación / Oferta**: Anuncio publicado por un prestador detallando su servicio, disponibilidad y zona de cobertura.
- **Solicitud de Servicio**: Pedido iniciado por un vecino hacia un prestador requiriendo un trabajo específico.
- **Zona / Barrio**: Delimitación geográfica para optimizar la búsqueda de prestadores cercanos y fomentar el comercio de proximidad.
- **Calificación / Reseña**: Valoración y testimonio del vecino solicitante una vez finalizado el trabajo.
